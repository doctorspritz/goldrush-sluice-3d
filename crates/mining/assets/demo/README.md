# Flowing demo fixture

Generated by `mining-physics/examples/make_demo.rs` on Apple M2 Max, 20 October 2026. Three finite terrain cuts are delivered to the hopper; the original FLIP/APIC, CPU DEM and terrain solvers advance until water and gangue actually leave the sluice. The file is a normal complete Session save compressed with zlib. It includes live particles, APIC/DEM contact state and terrain momentum, without manufactured recovery.

Rebuild with `cargo +nightly run -p mining-physics --example make_demo --profile playable --jobs 1 -- /tmp/flowing.json`, then zlib-compress that JSON into `flowing.json.zlib`. The application rejects an invalid fixture through the same save validation as gameplay.
